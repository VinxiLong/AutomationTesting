- Katalon Studio 10.4.3
- Java JDK 11 or higher

## How to Run Test Cases
1. Open Katalon Studio.
2. Go to **File → Open Project** → Open with project named "Automation Test"
3. Run Single test case from (Test Cases > TestCase1/TestCase2/TestCase3)
4. Direct run all test cases from (Test Suites > Run all)
5. Check Reports folder for execution results.

*run by click Start button (top right side)

## Test Cases Included
- TestCase1: Login with invalid credentials
- TestCase2: Login with empty input
- TestCase3: Forgotten password link validation
